Ox-Watt
=======

**Powering web applications**

Ox-Watt is an open-source collection of reusable libraries, utilities and development tools designed to simplify software development across multiple programming languages and ecosystems.

Originally developed as part of the Oxylus ecosystem, Ox-Watt aims to extract and generalize technologies that can be reused independently in other projects.

The project currently focuses on Python and TypeScript, with particular attention to software architecture, data management, developer productivity and integration with existing frameworks.

Goals
-----

Ox-Watt follows a few core principles:

* **Reusability:** Build generic components that can be shared across different projects.
* **Modularity:** Keep components focused, composable and independently usable.
* **Simplicity:** Prefer straightforward APIs and avoid unnecessary abstractions.
* **Interoperability:** Integrate with existing languages, frameworks and development ecosystems.
* **Open source:** Make reusable technologies available to the wider developer community.

Organization
------------

Ox-Watt brings together technologies developed for different programming languages and environments, organized into two main ecosystems: Python and TypeScript.

Each ecosystem has its own libraries, tools, dependencies, tests and documentation. Components are designed to remain as independent as practical, allowing them to be adopted individually without requiring the entire Ox-Watt ecosystem.

Some components provide general-purpose functionality and can be used independently of any application framework. Others integrate with specific environments, such as frontend or backend frameworks, or provide additional capabilities built on top of other Ox-Watt components.

The different technologies can also be combined when their responsibilities complement each other. This allows developers to use individual utilities where needed while benefiting from more integrated solutions when building complete applications.

Documentation, examples and development resources are maintained alongside their respective ecosystems, with general project information shared across the repository.

Technologies
------------

Ox-Watt currently focuses on two programming language ecosystems.

Python
~~~~~~

Python libraries and utilities for application development, automation and backend integration.

Components can be used independently or integrated with existing backend frameworks and application architectures.

TypeScript
~~~~~~~~~~

TypeScript libraries and utilities for application and frontend development.

Components range from framework-independent utilities and data management tools to integrations with frontend frameworks such as Vue.
