# Ox-Watt

**Reusable tools and building blocks for application development.**

Ox-Watt is a collection of reusable libraries, components and utilities designed to simplify application development.

It brings together independent building blocks that can be combined to build applications without imposing a monolithic framework or a predefined application architecture.

## Goals

- **Modularity** — Use only the parts your project needs.
- **Reusability** — Build on shared components and utilities instead of reinventing them.
- **Extensibility** — Extend existing functionality without coupling it to a specific application.
- **Interoperability** — Keep integrations and framework-specific code separate from reusable core logic.
- **Maintainability** — Favor clear APIs, explicit contracts and well-defined responsibilities.

## Packages

Ox-Watt is organized as a collection of packages, each with a focused responsibility.

Packages may provide framework-independent functionality, framework integrations, or higher-level components built on top of other Ox-Watt packages.

The package structure is intended to evolve as the project grows.

## Development

Ox-Watt is developed as a monorepo, allowing packages to be developed, tested and maintained together while retaining their independence.

Each package should document its own purpose, public API, dependencies and usage.

## Status

Ox-Watt is under active development. APIs and package boundaries may change as the project evolves.
